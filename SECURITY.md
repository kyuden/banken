# Security Policy

## Supported versions

Only the most recent minor release receives security fixes. The supported Ruby
and Rails versions are listed in the README.

## Reporting a vulnerability

Please do not open a public issue or pull request for a security problem.

Report it privately through
[GitHub Security Advisories](https://github.com/kyuden/banken/security/advisories/new).
If that page is unavailable, email the maintainer listed in the gemspec
(msmsms.um@gmail.com). You will get an acknowledgement, and a fix will be
released together with a CHANGELOG entry under "Security" and an advisory once
it is available.

Thank you for helping keep Banken's users safe.
